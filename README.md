## 📌 Project Overview

The **Stack Overflow Developer Survey 2024 – Technology Trends, Job Market & Developer Demographics** project is an end-to-end data analytics project focused on understanding the current technology landscape, future technology preferences, job-market demand, salary patterns, and demographic characteristics of developers.

The project uses data from the **Stack Overflow Developer Survey 2024**, along with job-posting data collected through a **Job API** and programming-language salary data obtained through **web scraping**. These multiple data sources were combined to provide a broader view of the developer ecosystem from both technology and career perspectives.

The analysis began with data collection and preparation, followed by data cleaning, transformation, exploratory data analysis, and visualization using Python. Various visualization techniques, including bar charts, line charts, histograms, box plots, scatter plots, bubble plots, pie charts, and stacked charts, were used to identify patterns, relationships, distributions, and trends within the data.

The project also compares **current technology usage with future technology preferences**, helping identify technologies that are already widely adopted as well as those developers are interested in working with in the future. The analysis covers programming languages, databases, platforms, and web frameworks.

To make the findings easier to explore and communicate, an interactive **IBM Cognos Analytics dashboard** was developed. The dashboard is organized into three major areas: **Current Technology Usage, Future Technology Trends, and Demographics**. The demographic analysis provides additional context about the developer population by examining factors such as age, education, and country.

The final results were presented through a structured PowerPoint presentation that converts the analytical results into clear findings and practical implications. Overall, the project demonstrates a complete data analytics workflow, from collecting raw data to transforming it into meaningful insights and an interactive dashboard.

## 🛠️ Technologies Used

- **Python** – Data analysis and processing

- **SQL** – Data querying and extraction
- **Matplotlib & Seaborn** – Data visualization
- **APIs** – Job-posting data collection

- **Microsoft PowerPoint** – Data storytelling and presentation

## 🔍 Key Insights

- **C** had the highest number of job postings in the collected dataset, with **25,114 postings**.
- **Swift** had the highest annual average salary among the analyzed programming languages, at **$130,801**.
- **JavaScript** was the most-used programming language and also showed strong future preference.
- **PostgreSQL** led both current database usage (**25,910 respondents**) and future preference (**26,904 respondents**).
- The **25–34 age group** represented the largest share of respondents at **41.3%**.
- **Bachelor's degree holders** formed the largest education group.
- **AWS, React, and Node.js** were among the prominent technologies identified in the technology analysis.
  

## 🎯 Conclusion

This project demonstrates how data analytics can be used to understand the rapidly evolving developer technology landscape and provide meaningful insights from multiple data sources.

The analysis shows that **JavaScript and PostgreSQL remain highly relevant technologies**, with strong representation in both current usage and future developer preferences. At the same time, technologies such as **TypeScript, React, Node.js, AWS, and other emerging tools** indicate the changing preferences and evolving skill requirements within the developer community.

The job-market and salary analysis also highlights that different programming languages can have significantly different levels of job demand and compensation. These differences provide useful information for developers when considering which technical skills to strengthen and for organizations when planning recruitment and workforce strategies.

The demographic analysis shows that the survey population is largely represented by **young and mid-career developers**, with the **25–34 age group** forming the largest segment and Bachelor's degree holders representing the largest education category.

Overall, the project highlights the importance of combining **data collection, data cleaning, exploratory analysis, visualization, and dashboarding** to transform raw datasets into actionable insights. The findings can support **developers, recruiters, hiring managers, learning and development teams, and organizations** in making more informed decisions related to technology adoption, hiring, training, and future skill development.

This project also demonstrates practical experience with an end-to-end analytics workflow using **Python, Pandas, NumPy, SQL, data visualization, APIs, web scraping, and IBM Cognos Analytics**, providing a strong foundation for real-world data analyst responsibilities.
